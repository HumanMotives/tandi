# VK miner (MVP)

Zoekt eerie spraaksamples op Internet Archive en knipt ze als WAV.
Pagina: humanmotives.org/vkminer/

Eenmalig: vul in vkminer/index.html je repo in bij GITHUB_REPO
(gebruikersnaam/reponaam, zoals in de GitHub-URL).

Starten: pagina → Nieuwe batch → op GitHub Run workflow.
Na 15–30 minuten de pagina verversen.

Instellingen (zoekopdrachten, trefwoorden, cliplengte): tool/config.yaml
Optioneel: GitHub-secret ANTHROPIC_API_KEY voor betere selectie.

Opruimen: oude mappen in batches/ verwijderen plus de regel in batches.json.
Niet alles op Internet Archive is publiek domein. Controleer de licentie voor je iets uitbrengt.
